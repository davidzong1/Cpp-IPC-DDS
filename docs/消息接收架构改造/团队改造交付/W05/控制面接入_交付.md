## 2. W04 §10 六条准入（逐条给**运行期**证据）

### 1.1 ⚠️ 一处**有意的行为变更**（原写"行为等价"已证伪；R1-W05-F1 → t75 更正）

**被更正的原话**（本包 §4.3 与归档 `.cc` 注释）：「无 peer 时扫描全部槽位的结果必然是 0，因此**行为等价**，
差别只在『无 peer 时不白扫 64 个槽位』。」

**为什么它错了**：`collect_stale_peers()` 判死的是 **PeerSlot**（`in_use/cc_id/pid/heartbeat`），
**不是** `peer_count`；而产品的清理顺序是 `remove_peer()` **→** `release_peer_slot()` 两步
（generation 重建分支与 `detach_on_exit()` 都是这个顺序）。进程若恰在两步之间消失，共享段就留下
**`peer_count==0` + `slot.in_use==1` + 心跳陈旧** —— 这正是该扫描存在的理由。此时 `has_peers()` 恒假
⇒ **该陈旧槽位在 `peer_count` 回到 >0 之前不会被回收**。

**如实登记为行为变更**（⛔ 不叫"等价"），代价两条：
1. **槽位 / cc_id 位在此期间不回收**（64 槽表 + cc 位图各占一项）；
2. **回收被推迟到"新订阅者已存在"那一刻才发生** —— 若那个陈旧 cc_id 位已被新订阅者复用，
   随后的 `disconnect_receivers(stale)` 会把它**误断**。

### 1.2 ⛔ N1：判定「何时扫 stale」曾被**复制到两条驱动源**（t84 已结构性修复）

**背景**：W05 有**两条驱动源** ——
① 进程级 `ShmControlScheduler`（默认臂）；② 每话题 `compat_control_loop()`（`DZIPC_SHM_CONTROL_SCHEDULER=1` 的 **L1 运行时回退**）。

**t77 的修复只落在①**（`Impl::dispatch()`），而②**自带一份同样判断且是修复前的形态**：

```cpp
// src/dzIPC/shm_pub_sub_ipc.cc compat_control_loop()（t77 时点，⛔ 已修）
pub_control_state_->on_pub_heartbeat(...);
if (pub_control_state_->has_peers())          // ← 同一道门控，原样保留
{
    pub_control_state_->on_pub_stale_scan(...);
}
```

⇒ 走 L1 回退时**正确性回归原样复现**：`DZIPC_SHM_CONTROL_SCHEDULER=1` 下 **400 发 0 收**（4/4 次一致），
而基线是 400/400。**回退臂比基线更差** ⇒ L1 作为**回滚入口**是不安全的（t78 的 N1）。

**根因（一句话）**：**同一判据被复制到两条驱动路径** —— 修一条、漏一条。
这与本轮已出现的其它"同一事实多处判定"同族：W10-F7（渲染与断言不一致）、W08（失效值两处并存）。

**修法 = (B) 路线：把判据做成**唯一的内联自由函数**（`pub_control_tick()`，**唯一一处**）：

| 层 | 内容 |
|---|---|
| 契约 | `include/dzIPC/threepools/shm_control_scheduler.h` 新增**内联自由函数** `pub_control_tick(pub, now, dead_timeout, st)`（⛔ **不是**虚成员 —— 见下「为什么不用成员函数」）：内在顺序 = ① 无条件 `on_pub_heartbeat` ② `has_peers()`（抛则只放弃本拍判定）③ 真 ⇒ 每拍扫；假 ⇒ `dead_timeout` 同量级低频兜底扫。「下次该扫的时刻」放在驱动方自持的 `PubTickState` 里（每驱动方一份） |

⚠️ **为什么判据做成自由函数而不是 `PubControlState` 的（非虚）成员函数**（t84 初版踩坑）：
把状态放进 `PubControlState` 会**改变这个导出抽象基类的布局**（③d 硬闸）⇒ 任何**派生它的二进制**
（含测试替身）都会按旧尺寸构造，新成员被写花 —— 首轮实测表现为 `test_shm_control_scheduler`
的 `TimingSemanticsUnchanged` / `CallbackExceptionIsIsolated` **乱红**（`owner_hb` 变成负巨值）。
**自由函数 + 驱动方自持状态** ⇒ `sizeof(PubControlState)` 仍为 **8**（仅 vtable 指针），
⛔ 布局零变化、无 ABI 影响；而「逻辑只一处」的结构目标同样达成。

**为什么 (B) 能结构性防复发**（不是"两处各自实现一遍然后祈祷一致"）：
判据的**状态与分支只存在一份**；两条驱动源都只是"按时拍一下"。
⇒ 今后任何一处想改「何时扫」，都只能改 `pub_control_tick()`，**两条驱动源自动同步**；
⛔ 也不可能再出现"修了默认臂、回退臂仍带旧判据"的形态（消融实验已验证，见下）。

## 4. 特性开关与回滚

### 4.1 开关（⚠️ 极性陷阱，必须显著标注）

```text
DZIPC_SHM_CONTROL_SCHEDULER   —— 取值语义**与 socket 侧相同**（t75 按 R1-W05-F4 更正措辞）：
  未设      ⇒ 进程级调度器（新路径）
  空串 ""   ⇒ 进程级调度器（新路径）
  字面 "0"  ⇒ 进程级调度器（新路径；与"未设"同义，便于脚本统一写）
  其它任何非空值（"1" / "compat" / "legacy" / "2" …） ⇒ **强制每话题兼容控制线程（回退）**

对照 socket 侧 DZIPC_SOCKET_COMPAT_THREAD（实测两侧真值表**逐值相同**）：
  未设 / "" / "0" ⇒ 新路径 ; "1" / "compat" / "2" / "00" / "legacy" ⇒ 回退
  ⇒ **两侧取值语义相同**；SHM 侧**额外接受字面 `0` 作为显式新路径的写法（与 unset 同义）**，
     这只是多一个"写起来顺手"的等价取值，⛔ **不是**"极性相反"。
  ⇒ 代码级唯一差异是 SHM 的 lambda 多一个等价的早返回分支（socket 侧用
     `return !(v[0]=='0' && v[1]=='\0')` 表达同一语义），**语义等价**。
```

> **本包修正的一处文档缺陷**：`include/dzIPC/shm_pub_sub_ipc.h` 原先写作「显式回退 `DZIPC_SHM_CONTROL_SCHEDULER=0`」，
> **与实现相反**。我按源码 + 四值实测更正为「非空且非 `0` ⇒ 回退」，并在头文件里加了 4 行显式警告。
> 实测证据：`unset→process-scheduler`、`0→process-scheduler`、`1→compat-per-topic-thread`、`compat→compat-per-topic-thread`。
> ⛔ 该缺陷会**直接误导回滚操作**（想让 SHM 侧回退却写了 `0`，实际得到的是新路径），建议纳入 W12《运行与回滚》已知易错点。
>
> ⚠️ **t75 二次更正（R1-W05-F4）**：本包 §4.1 原文把关系写成「**极性与 socket 侧相反**」，**不准确**。
> R1 的两侧同值对照实测：**两侧真值表逐值相同**（`unset`/`""`/`"0"` ⇒ 新路径；其它非空 ⇒ 回退），
> SHM 侧**没有**"socket 侧不存在的新路径取值"—— `0` 与 `unset` 同义，只是多一种写法。
> 故正确表述是「**两侧取值语义相同；SHM 侧额外接受字面 `0` 作为显式新路径（与 unset 同义）**」。

### 10.1 用例源码（`gate_case.cpp`，**101 行**，⛔ 只读探针、不依赖崩溃时序）

```cpp
/* 构造「peer_count==0 但 PeerSlot 仍 in_use」这一合法可达状态，并观察发布端是否回收该槽位。
 * 该状态的来源(产品自身路径): 订阅端清理顺序是 remove_peer() → release_peer_slot()
 * (重建分支与 detach_on_exit 同序)。进程恰死在两句之间即到达。
 * 本探针不依赖崩溃时序: 直接用控制面 API 把终态造出来(add_peer → acquire_peer_slot → remove_peer),
 * 再看真实发布端在 >2×peer_dead_timeout(2s) 内是否清掉槽位、以及活订阅者是否被误断。
 * 用法: gate_case <domain> <publish_n> <hold_ms> [nocraft] */
#include <chrono>
#include <cstdio>
#include <cstdlib>
#include <memory>
#include <string>
#include <thread>
#include "dzIPC/common/control_plane.h"
#include "dzIPC/common/name_operator.h"
#include "dzIPC/common/topic_data.h"
#include "dzIPC/shm_pub_sub_ipc.h"
#include "libipc/shm.h"
#include "ipc_msg/std_msgs/std_string.hpp"
using Clock = std::chrono::steady_clock;
using dzIPC::control_plane_shm::TopicControl;
static constexpr std::uint32_t kMsgId = 93;
#define SAY(...) do { std::printf(__VA_ARGS__); std::fflush(stdout); } while (0)
struct Raw
{
    ipc::shm::handle h; TopicControl* c{nullptr};
    bool open(const std::string& n)
    {
        if (!h.acquire(n.c_str(), sizeof(TopicControl), ipc::shm::open)) return false;
        c = static_cast<TopicControl*>(h.get());
        return c && c->magic.load() == dzIPC::control_plane_shm::kTopicControlMagic;
    }
    unsigned in_use(int i) const { return c->peers[i].in_use.load(std::memory_order_acquire); }
    unsigned count() const { return c->peer_count.load(std::memory_order_acquire); }
    unsigned cc(int i) const { return c->peers[i].cc_id.load(std::memory_order_acquire); }
};
int main(int argc, char** argv)
{
    const long dom = argc > 1 ? strtol(argv[1], nullptr, 10) : 8899;
    const int pub_n = argc > 2 ? atoi(argv[2]) : 200;
    const int hold_ms = argc > 3 ? atoi(argv[3]) : 4500;
    const bool craft = !(argc > 4 && std::string(argv[4]) == "nocraft");
    const std::string topic = "t58harm_" + std::to_string(dom) + "_0";
    const std::string seg = shm_topic_control_name(topic, (size_t)dom);
    const char* v = ::getenv("DZIPC_SHM_CONTROL_SCHEDULER");
    const bool fb = (v != nullptr && v[0] != '\0' && !(v[0] == '0' && v[1] == '\0'));
    SAY("arm=%s dom=%ld craft=%d\n", fb ? "compat" : "process-scheduler", dom, (int)craft);

    auto td = std::make_shared<dzIPC::TopicData>(std::make_shared<dzIPC::Msg::StdString>(), kMsgId);
    dzIPC::shm::shm_pub_ipc pub(td, topic, (size_t)dom, true);
    pub.InitChannel("t58harm");
    /* ⚠️ 必须在 InitChannel 之后造状态: InitChannel 会 begin_rebuild()
     *    (control_plane.cc 的 begin_rebuild → clear_all_peer_slots), 把先造的状态清掉。 */
    if (craft)
    {
        dzIPC::control_plane_shm::TopicControlPlane cp;
        if (!cp.open(seg)) { SAY("open_fail\n"); return 2; }
        const uint32_t gen = cp.generation();
        if (!cp.add_peer(gen)) { SAY("add_peer_fail\n"); return 3; }
        const int slot = cp.acquire_peer_slot(gen, 1u);
        cp.remove_peer(gen);                 /* peer_count → 0, 槽位保持 in_use */
        Raw r; if (!r.open(seg)) { SAY("raw_open_fail\n"); return 4; }
        SAY("crafted peer_count=%u slot=%d in_use=%u cc_id=%u\n", r.count(), slot, r.in_use(0), r.cc(0));
        if (slot < 0 || r.count() != 0 || r.in_use(0) == 0) { SAY("craft_failed\n"); return 5; }
        std::this_thread::sleep_for(std::chrono::milliseconds(hold_ms));
    }
    { Raw r; r.open(seg); SAY("after_hold(%dms) peer_count=%u slot_in_use=%u cc=%u\n", hold_ms, r.count(), r.in_use(0), r.cc(0)); }

    dzIPC::shm::shm_sub_ipc sub(td, topic, (size_t)dom, false);
    sub.InitChannel("t58harm");
    std::this_thread::sleep_for(std::chrono::milliseconds(300));
    {   /* 找出真实订阅者占用的槽位与 cc_id（用于判定 reap 是否打到活订阅者） */
        Raw r;
        if (r.open(seg))
        {
            SAY("live_slots:");
            for (int i = 0; i < 8; ++i) if (r.in_use(i)) SAY(" [%d]=cc%u", i, r.cc(i));
            SAY("\n");
        }
    }
    long rx = 0, mism = 0;
    for (int i = 0; i < pub_n; ++i)
    {
        auto m = std::make_shared<dzIPC::Msg::StdString>();
        m->set_msg_id(kMsgId);
        m->str = "harm-" + std::to_string(i);
        pub.publish(m);
        std::this_thread::sleep_for(std::chrono::milliseconds(2));
        auto sink = std::make_shared<dzIPC::TopicData>(std::make_shared<dzIPC::Msg::StdString>(), kMsgId);
        if (sub.try_get_clone(sink))
        {
            auto* p = dynamic_cast<dzIPC::Msg::StdString*>(sink->topic().get());
            const std::string want = "harm-" + std::to_string(i);
            if (p != nullptr && p->str == want) ++rx; else ++mism;
        }
    }
    std::this_thread::sleep_for(std::chrono::milliseconds(500));
    { Raw r; if (r.open(seg)) SAY("final peer_count=%u slot_in_use=%u cc=%u\n", r.count(), r.in_use(0), r.cc(0)); }
    SAY("published=%d received=%ld mismatch=%ld\n", pub_n, rx, mism);
    SAY("T58_HARM_DONE\n");
    _exit(0);
}
```
