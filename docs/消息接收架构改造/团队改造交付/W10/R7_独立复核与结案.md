### 1.2 载荷逐字节重算（可判性证明，非仅核计数）

工装的载荷由 `(route_idx, seq)` 确定性生成：前 16 B = `seq`(4) + `route_idx`(4) + `magic = 0xA5A5A5A5DEADBEEF ^ (seq*2654435761)`(8)，
其余字节 = `(route*31 + seq*131 + i*7) & 0xFF`；接收端**逐字节重算**后比对。
我按**同一公式**独立重算，并检验「实际用到的 `(route,seq)` 对的载荷是否两两不同」：

| run | 用到的 (route,seq) 对 | 载荷去重后个数 | 碰撞 |
|---|---|---|---|
| r25 SHM | 3005 | 3005 | **0** |
| r27 sock f1 | 1005 | 1005 | **0** |
| r28 sock | 3005 | 3005 | **0** |
| r28 SHM#1 | 3006 | 3006 | **0** |
| **r46 my SHM** | 3006 | 3006 | **0** |

⇒ **载荷在该 (route,seq) 集合上是单射** ⇒ 「某 route 校验通过 N 条」**不能**由「另一 route 的帧」凑成。
这条把「逐字节校验」从「代码里写了」升级为「本 run 的数据上可判」。
