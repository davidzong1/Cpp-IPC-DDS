## 3. 接口变更流程（冻结后）

1. 变更方在 `团队改造交付/W00/接口变更申请-<WP>-<序号>.md` 提交：**动机、影响面（文件/符号）、兼容性、回滚方式、需要的评审者**。
2. 架构负责人裁决「是否改变冻结契约」；涉及共享内存布局/ABI 的，必须附**混合版本行为**说明（方案 §2.3）。
3. 变更落地后，由**非变更者**复核并在 `基线与门槛.md` §11 追加记录（原值/新值/依据/生效 `run_id`）。
4. 未走流程的契约改动一律视为「未授权变更」，不得作为验收依据。
