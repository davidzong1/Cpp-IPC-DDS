## 1. 复算方法学（先说清「我怎么取信一个时间戳」）

`mtime` 在本仓**不可用于判定 run 的起止**（run 目录的 mtime = 收尾写入时刻，log 的 mtime 会被后续 append 刷新）。我用 **`stat -c %W`（birth time）**，并**先用一次自建 run 校准语义**：

```
$ date '+启动 T0 = %H:%M:%S'          → 启动 T0 = 09:30:30
$ ./build/bin/w10_r5_matrix ... --window-s 5 --settle-s 1 ... > build/t66/cal.log
$ date '+结束 T1 = %H:%M:%S'          → 结束 T1 = 09:30:37
$ stat -c "%w" build/t66/cal.log      → 09:30:31.64   ← **log birth ≈ run 启动**
$ stat -c "%w" build/t66/cal          → 09:30:37.66   ← **dir birth ≈ run 结束**
```
⇒ 校准结论：**`log birth` = run 开始、`dir birth` = run 结束**。以下所有时间判定均据此。
（⚠️ 我第一轮误用「fingerprint.txt 的 `started=` 行」当首 run 起点，得出「重叠」的**假阳性**；改用 birth 后仍**确认**存在重叠，但**精确窗口**是 16:17:55–16:18:16 而非 16:17:29 起。两次都指向同一结论，但我以校准后的 birth 口径为准。）
