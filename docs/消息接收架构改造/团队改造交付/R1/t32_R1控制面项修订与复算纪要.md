## 3. 修订后的判定式（rev-2，全部输入已冻结）

```
空闲 ctx ≤ ⌈ 池项 + 控制面项 ⌉ × 1.5
  池项        = N_worker × 1000/wait_timeout_ms = 32 × 1000/100 = 320 /s        （不变）
  控制面项    = Σ_在册控制项(1000/heartbeat_ms) / B_min   ← 默认路径（同批合并）
              = Σ_在册控制项(1000/heartbeat_ms)           ← 回退路径（每项一线程）
  Σ(2000 项)  = 1000×(1000/10) + 1000×(1000/50) = 120000 /s
  B_min       = 6.0（批均因子冻结下界；实测下界 6.41）
默认臂阈值 = (320 + 20000) × 1.5 = 30480 /s    实测 8864.6–9101.1 ⇒ 余量 3.43×
回退臂阈值 = (320 + 120000) × 1.5 = 180480 /s  实测 119997–141376 ⇒ 余量 1.28–1.50×
```

**冻结输入**（含原 R-1 未冻结的「注册散布 ≤ 10 ms」「窗口 ≥60 s」「统计口径」）：见 `基线与门槛.md` §11.3 rev-2「（二）冻结输入表」11 项。

**判定式为何可保留**：`Σ/B_min` 对 `sub_heartbeat`/`pub_heartbeat`/在册项数**保持单调敏感**——若把调度器改成逐项 tick（B→1），`ctx` 会趋近 Σ 并**正确地判失败**；而冻结一个取样值做不到这点。
