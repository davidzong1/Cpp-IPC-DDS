3. **E-D 必须附口径**：进程模型 / 等待方式 / 计时边界 / 消费工作 / 探针 scope，缺一不可。
4. **外部结论必须指向存证**：指向 `main` 分支的链接一律不可引用（会漂移）；用 `W01/外部来源存证/` 内的固定版本文件。
5. **只追加不覆盖**：原始样本、历史报告、修订前快照一律只追加；任何修订都必须新增快照并记录 sha256。
6. **不跨 WP 改写**：各 WP 只写自身子目录与本 WP 交付物；发现自己引用了已被删除的结论，回报文档负责人统一纠偏，不自行改他人正文。
