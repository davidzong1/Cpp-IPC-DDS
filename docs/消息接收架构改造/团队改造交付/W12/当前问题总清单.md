## 5. 结构性风险（会复发，非一次性）

本轮库指纹换代 **≥6 代**：`cf209393` → `f0ebc3ef` → `dbca161e` → `0298b1df` → `d0f581d1` → `36c17c7b` → …

- W06 报告引用的 `recv_worker.cc` sha **`git cat-file` 已不可核对**（Not a valid object name）
- W09 引用的指纹 `dbca161e…`/`0298b1df…` **全盘 find 0 命中**
- W11 `manifest.binary_sha256` 是**生成时**快照、与**采集时**的 `fingerprint.txt` 差代（**N1**）
- t74 观测到 `kRounds` 11:46 为 **2000**、11:49 被改 **1200**（并发改动）

⇒ **「读数 → 库」的绑定在单工作树并发环境下无法长期稳定**。W00 的 R0-A1 双指纹纪律**必要但不充分**。
