### 1.5 我另发现的一处**分母术语陷阱**（R-1c，⛔ 不写成已解决）

```

```
工装的 `endpoints = 2*(broadcast?1:n) + 2*n`（`w10_matrix.cpp:1701`）**其量纲实为「fd 数」而非「端点」**（算术上 `predicted` 两侧一致，都 4068，所以不影响该行结论）——但它与 R-1c 的「端点」**同名不同义**：

- 若有人误用工装的 `4000` ⇒ `4068/4000 = 1.017`，看起来余量巨大 ⇒ **假安全**。
⇒ **建议**（归 R3 工装 owner）：把工装输出字段名改为 `fd_est`/`fd_slots` 或直接用 `endpoints_2000`，避免下游把两者混用。
