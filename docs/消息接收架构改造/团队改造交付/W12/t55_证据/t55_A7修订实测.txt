## 5 顺带修正的一处既有缺陷（A7 内）
原 A7 的 `ctest --test-dir build -j4 | tail -2` **看不到判定行**（末 2 行是**空行** + `Total Test time`）⇒ rev-2 改 `tail -3`，使 `100% tests passed / N tests failed` **可见**。
```
$ ctest --test-dir build -j4 | tail -2      # 原：看不到判定行
  (空行)
  Total Test time (real) =  55.66 sec
$ ctest --test-dir build -j4 | tail -3      # 改后：判定行可见
  100% tests passed, 0 tests failed out of 29
  (空行)
  Total Test time (real) =  55.72 sec
```
⛔ **不做硬失败**：该套件有 D-13 已知残段偶发（实测 5 轮中 1 次 28/29）⇒ 硬失败会让 **A7 自身变成偶发失败项**；正确做法是**打印判定行 + 报轮数**。
