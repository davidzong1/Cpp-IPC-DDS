## 3. 线程数与上下文切换 / 空闲 CPU

探针：`test/perf/out/20260927_t6_probes/t6scale.cpp`（**按当前头文件重编**，见 §10 的 ABI 陷阱说明）。
口径：创建 scale 个 socket 订阅者 + 1 发布者 → 静默窗口 2000ms，每 200ms 采样
`/proc/self/task` 线程数、`/proc/self/status` 的 voluntary/nonvoluntary_ctxt_switches、`/proc/self/stat` 的 utime+stime。

```bash
env -u DZIPC_SOCKET_COMPAT_THREAD -u DZIPC_SOCKET_RECV_WORKERS \
  .t6_probe/t6scale --scale=477 --idle-ms=2000 --sample-ms=200 --domain=122
```

### 3.1 接收线程数：不随规模线性增长

| scale | **worker（本波）** threads_max | worker threads_min | compat threads_max | **基线库** threads_max |
|---|---|---|---|---|
| 1 | **33** | 2 | 2 | 5 |
| 100 | **33** | 2 | 101 | 104 |
| 477 | **33** | 2 | 478 | 481 |
| 1000 | **33** | 2 | **abort** | （基线 1000 实测 abort：日志停在 `created 500/1000`） |

> 基线库边界说明：477（481 线程）与 511 均 rc=0 存活，scale=1000 时 abort ⇒ 与 D9 一致，触发量取决于**实际 fd 号**而非订阅个数。

* worker 路径 **threads_max 恒为 33**（= 32 个共享 worker + 主线程），scale 从 1 增到 1000 **完全不增长**
  ⇒ **不存在 per-route/per-subscription 代理线程**。
* `threads_min = 2` ⇒ 静默后共享池**整体归还**（空闲退出生效，见 §7）。
* compat 路径与基线库均为**线性**（≈1 线程/订阅者、基线 477 时 481 线程），构成对照组。
* worker 细节：`workers 32` 来自默认 `worker_count == 0 ⇒ hardware_concurrency()`（本机 32 核）。

## 4. 与 shm_pub_sub 基准的行为一致性对照

### 4.1 结构性保证：三条收包路径**共用同一函数**（构造性一致）

## 10. 方法与陷阱（供后续复用）

1. **`/tmp` 不跨 bash 调用持久**（本 harness 实测：写入后下一次调用即消失）⇒
   探针与证据必须落工作区内持久目录（本波用 `.t6_probe/`，镜像到 `test/perf/out/`）。
2. **预编译探针 ABI 陷阱（重要）**：`build_baseline/bin/baseline_probe_after` 是按**改造前头文件**编译的，
   而本波给 `socket_sub_ipc` 增加了数据成员（`receive_state_`/`receive_route_`/`worker_mode_`/`receive_generation_`，
   `sizeof(socket_sub_ipc)=304`）⇒ 布局不匹配，用它测当前库会得到
   `malloc.c:2617 sysmalloc Assertion` **堆损坏**，**那不是库的缺陷**。
   ⇒ 测当前库必须**按当前头文件重编探针**（本报告全部当前库读数均如此）。
   ⇒ 该二进制对**基线库**仍有效（`baseline_probe` ↔ `build_baseline/lib` 配对），故仍用于基线对照。
3. **先排除探针自身再上报**：期间两次自伤（`--k=v` 解析缺失导致误读 `worker_count=32`；
   `queue_size=8` 导致 `received=8/20` 被误读为丢包）。两次都经核对源码/参数后确认是探针问题。
4. **`env` 选项必须前置**：`env VAR=1 -u OTHER cmd` 会把 `-u` 当成命令（rc=127）。
   正确写法 `env -u OTHER VAR=1 cmd`，或先 `export`。
5. **gtest 计时会污染日志差分**：比对 worker/compat 前必须归一化掉 ` (N ms)` 与 ANSI 颜色码。
6. **`make -q` 返回 1 是正常**（`generate_ipc_messages` 自定义目标每次必跑），不代表产物陈旧。
7. **`DZIPC_SOCKET_RECV_WORKERS` 与 `DZIPC_SOCKET_COMPAT_THREAD` 都要清**，
   前者被共享层 static 缓存且**静默**改写线程数口径，风险等级与后者相同。
