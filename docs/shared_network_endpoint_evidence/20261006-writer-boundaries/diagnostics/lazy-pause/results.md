# R02：延后暂停 worker 的通知对照

仅省去 acquire 时主动 interrupt，release 的强制重查和通知保留。核心功能回归 3/3 通过，最终因无稳定端到端收益撤回。

1 SUB/4KiB、32 SUB/64B 各按改前、改后、改后、改前，预热 2 秒、采样 10 秒，100 Hz；接收/发布 CPU 诊断开启。8000 次发布、132000 次接收完整。

32 订阅者的均值在部分窗口下降，但 p99 不稳定；单订阅 4 KiB 两个候选窗口均明显比改前慢。不能用降低通知次数代替实际延迟验收，因此不接入生产。

首轮观测、租约复用和本轮均显示无绑核短窗波动显著。本机 C2/C3 的公布退出延迟为 127/1048µs，且未禁用；这是待验证假设，尚无逐样本调度/空闲态因果证据。perf_event_paranoid=4，普通 perf 被拒绝，sudo -n 需要密码；未调整 sysctl 或电源配置。
