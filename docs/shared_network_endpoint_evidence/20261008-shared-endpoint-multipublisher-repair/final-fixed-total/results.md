# 本项目多发布交付修复验证

版本依据为上级目录 `final-provenance.json` 的实际源码 diff 和二进制 SHA256。只运行本机共享端点 `IPC_SOCKET + shared_v1`，不测试其他框架。

各发布者为独立进程、同一话题，按共同单调时钟起点发布。2 秒预热、10 秒正式、3 轮、窗间静默 2 秒。接收阻塞等待，CPU0–31 全部允许；未调整池容量、绑核或调度策略。

验收从原始 CSV 按每个订阅者的（发布者 ID，独立序号）集合复算，并核对逐字节校验、序号顺序、拒绝、迟发、日志和产物哈希。状态保留原工装结果；迟发与交付错误分别记账。
