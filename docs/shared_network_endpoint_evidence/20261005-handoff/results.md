# 暂停重复等待与后台交接修复

方案提交3320a79；上一协作版f6f4b88完整矩阵剩余5/27失败，原记录保存在20261005-assist/。

## 实现

getter的协作作用域绑定具体worker注册Entry，复用其shared_ptr。第一个getter暂停该条目的SHM等待，最后一个退出恢复等待并标记立即重查；不新增线程、不等待在途worker、不改变owner与消费锁。暂停保留等待槽位及序号，worker不把暂停当空读。旧代次Entry释放不会恢复新注册。纯try_get或队列已有消息跳过暂停。有限等待的截止时间包含交接开销。

暂停worker后，getter若先收到另一类队列消息，会继续处理已有SHM积压直到目标消息/空读/原期限；TLV/视图互不吞消息。后端失败退回条件变量前先恢复后台接收。独立worker唤醒不再remove/add条目，避免意外清除暂停状态。
