# dzplot 的 3D 显示与示例

3D 后端、组件、网页和示例已迁入 dzplot。统一使用一个服务，曲线为主页面，3D 为子页面，支持曲线与 3D 分栏查看。

```bash
# 推荐入口
python3 tools/dzplot/main.py --demo
# 浏览器：http://127.0.0.1:8766/#viz 或 /#split

# 加载原 3D 配置（实时模式请使用与 dzIPC 绑定匹配的 Python）
python3.10 tools/dzplot/main.py \
  --config tools/dzplot/demo/robot_state_config.json --load-config
```

完整操作、布局、参数、数据共享和验证说明见 [dzplot 使用说明](README.md)。直接访问统一服务的 `/viz/` 可打开带导航的 3D 子页面。

## 显示类型与操作

| 类型 | 效果 |
|---|---|
| Pose / Path / Marker | 位姿轨迹、路径和标记 |
| PointCloud | 二进制点云、渐进地图、自适应 GPU 降采样 |
| Image | JPEG / PNG / RGB8 / BGR8 / RGBA8 / BGRA8 / Mono8 浮窗；支持拖动和缩放 |
| TF | 坐标系变换 |
| Robot | URDF 模型，支持 OBJ / STL 网格、连杆坐标系与关节轴 |
| RobotState | 将关节状态应用到关联机器人 |
| RawMessage | 查看原始元信息 |

滚轮缩放，左键旋转，右键平移。添加显示时选择实时订阅或工作区回放 / 嗅探数据；使用工作区数据不会新增 IPC 订阅。实时 3D 话题的数值字段会自动出现在曲线页面。

## 实时 demo

以下发布端和所需的图像、URDF、OBJ 网格均位于 `tools/dzplot/demo/`。先启动统一工作区，在 3D 中添加对应类型、话题，域编号 0，传输 shm；再勾选「显示」。

```bash
python3.10 tools/dzplot/demo/send_point_cloud_demo.py --topic /demo/cloud
python3.10 tools/dzplot/demo/send_image_demo.py --topic /demo/image
python3.10 tools/dzplot/demo/send_robot_state.py --topic /demo/robot_state
```

机器人 demo 可先使用 `--prepare-only --no-download` 生成配置，再用统一入口的 `--config … --load-config` 加载。机器人模型必须先于关联的 RobotState 显示存在。

## 配置与依赖

原 JSON 配置的 `domain`、`transport`、`queue`、`poll`、`extra`、`dzflat`、`topics`、`robot_displays`、`robot_state_displays`、`robot_models` 均保留。3D 配置面板按服务端路径保存 / 加载；URDF 可内联或使用 `urdf_path`，网格通过统一服务读取。

SHM 默认开启 DZFlat 借样。接收端自动处理 TLV / DZFlat，所用 Python 必须能导入对应 `_dzipc_core`。示例发布端会按链路、握手和 schema 状态回退 TLV。首次借样会在终端输出 `DZFlat wire detected`。Three.js 固定版本与 MIT 许可证保存在 [离线依赖](web/viz/vendor/README.md) 中。

```bash
python3 tools/dzplot/test/test_visualizer_components.py --integration --browser
python3 tools/dzplot/test/test_workspace.py --browser
```
